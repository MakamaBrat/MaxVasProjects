# Портфолио игр

Статическая страница-портфолио: наверху телефон-консоль с портативными играми (переключение стрелками/свайпом), ниже — горизонтальная полка с играми для больших экранов.

## Структура

```
index.html
style.css
script.js
assets/
  mobile/    ← сюда портретные (вертикальные) гифки для телефона
  desktop/   ← сюда горизонтальные гифки для нижней секции
```

## Как добавить свои игры

1. Положи гифки в `assets/mobile/` (портретные, под экран телефона, идеально 9:19.5) и `assets/desktop/` (горизонтальные, 16:9).
2. Открой `script.js`, там наверху два массива — `MOBILE_GAMES` и `DESKTOP_GAMES`.
3. Для каждой игры поменяй:
   - `title` — название
   - `description` — описание
   - `gif` — путь до файла, например `assets/mobile/my-game.gif`
   - `tags` — короткие теги (жанр, движок и т.п.)
4. Можно добавлять/удалять игры — просто добавь или убери объект в массиве, всё остальное (счётчик, точки, карточки) пересчитается само.

Пока гифки нет по указанному пути — на её месте будет аккуратная заглушка с надписью и путём к файлу, ничего не сломается.

## Локальный просмотр

Открой `index.html` в браузере, либо запусти локальный сервер:

```bash
npx serve .
```

## Деплой на Vercel

Вариант 1 — через сайт:
1. Зайди на vercel.com → **Add New → Project**.
2. Загрузи эту папку (или подключи Git-репозиторий с этими файлами).
3. Framework Preset — **Other** (это просто статичные файлы, билд не нужен).
4. Deploy.

Вариант 2 — через CLI:
```bash
npm i -g vercel
cd portfolio
vercel
```

Никакой сборки не требуется — это чистые HTML/CSS/JS файлы.
