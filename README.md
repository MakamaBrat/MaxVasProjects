# Портфолио игр

Статическая страница-портфолио:
- вверху — плашка "PORTFOLIO", статистика (50+ проектов, 4+ года опыта) и переключатель языков (UKR / RUS / ENG);
- секция "Портативные" — грид маленьких превью всех мобильных игр; клик по карточке анимированно открывает полноэкранный вид с телефоном, стрелками, описанием и тегами технологий;
- секция "На большом экране" — горизонтальная полка проектов.

## Структура

```
index.html
style.css
script.js
assets/
  mobile/    ← портретные гифки/видео для телефона
  desktop/   ← горизонтальные гифки для нижней секции
```

## Как добавить/изменить игру

Всё в `script.js`, в массивах `MOBILE_GAMES` и `DESKTOP_GAMES`:
- `title` — название (не переводится, показывается одинаково на всех языках)
- `gif` — путь до файла. Поддерживаются и .gif, и видео (.mp4/.webm/.mov) — тип определяется по расширению автоматически
- `tags` — теги технологий/жанра. Жанровые слова (Аркада, Пазл, Гонки и т.п.) переводятся сами через словарь `GENRE_TR`, названия технологий (Unity, Firebase...) везде остаются как есть
- `description` — объект `{ ru, uk, en }` с описанием на трёх языках

## Языки

Тексты интерфейса лежат в объекте `UI` в `script.js` (ключи `ru`, `uk`, `en`). Выбор языка сохраняется в `localStorage`, при следующем визите откроется тот же язык.

## Локальный просмотр

```bash
npx serve .
```

## Деплой на Vercel

1. vercel.com → **Add New → Project**
2. Загрузи эту папку или подключи Git-репозиторий
3. Framework Preset — **Other** (сборка не нужна, чистые статичные файлы)
4. Deploy

Либо через CLI:
```bash
npm i -g vercel
cd MaxVasProjects
vercel
```
